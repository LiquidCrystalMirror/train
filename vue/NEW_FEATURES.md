# 前端新增功能说明

## 概述
根据"只添加不修改"的原则，我为火车售票系统前端添加了以下新功能页面和增强功能。

## 新增页面

### 1. 首页/仪表盘 (DashboardHome.vue)
**路径**: `/dashboard/home`  
**文件**: `vue/src/views/DashboardHome.vue`

**功能特点**:
- 统计卡片展示（用户总数、车次总数、车票总数、订单总数）
- 欢迎信息和用户角色显示
- 快捷操作按钮（根据权限显示不同功能）
- 美观的渐变色彩设计

**适用场景**: 
- 登录后默认进入的首页
- 快速了解系统概况
- 快捷访问常用功能

---

### 2. 车次查询页面 (SearchView.vue)
**路径**: `/dashboard/train-search`  
**文件**: `vue/src/views/train/SearchView.vue`

**功能特点**:
- 多种查询方式：
  - 按起止站点ID查询
  - 按时间范围查询
  - 按车次号查询
- 查询结果展示车次详细信息
- 查看车次的可用座位
- 直接购买车票入口

**适用场景**:
- 普通用户查询车次
- 管理员快速查找车次
- 购票前的车次浏览

---

### 3. 我的订单页面 (MyOrdersView.vue)
**路径**: `/dashboard/my-orders`  
**文件**: `vue/src/views/orders/MyOrdersView.vue`

**功能特点**:
- 两个标签页：
  - **我的购票**: 查看个人购票记录
  - **我的退票**: 查看个人退票记录
- 支持在线退票功能
- 订单状态实时显示
- 基于当前登录用户过滤数据

**适用场景**:
- 用户查看自己的购票历史
- 用户管理自己的订单
- 快速办理退票

---

## 路由配置更新

在 `vue/src/router/index.js` 中添加了以下新路由：

```javascript
{
  path:'/dashboard/home',           // 首页
  name:'home',
  component:()=>import('@/views/DashboardHome.vue')
},
{
  path:'/dashboard/train-search',   // 车次查询
  name:'trainSearch',
  component:()=>import('@/views/train/SearchView.vue')
},
{
  path:'/dashboard/my-orders',      // 我的订单
  name:'myOrders',
  component:()=>import('@/views/orders/MyOrdersView.vue')
}
```

同时设置了 Dashboard 默认跳转到首页：
```javascript
redirect: '/dashboard/home'
```

在 `vue/src/views/Dashboard.vue` 中更新了侧边栏菜单：

- `Search` - 查询图标

## 技术亮点

### 1. 响应式设计
所有新页面都采用了 Element Plus 的栅格系统，确保在不同屏幕尺寸下都有良好的显示效果。

### 2. 用户体验优化
- 加载状态提示
- 操作确认对话框
- 成功/失败消息提示
- 表单验证

### 3. 权限控制
- 首页根据用户角色显示不同的快捷操作
- 管理员和普通用户看到的功能不同

### 4. 代码规范
- 使用 Composition API (`<script setup>`)
- 统一的API调用方式
- 清晰的注释和代码结构

## 使用建议

1. **首次启动**:
   - 确保后端服务已启动
   - 运行 `npm install` 安装依赖
   - 运行 `npm run dev` 启动前端

2. **测试流程**:
   - 登录系统
   - 查看首页统计信息
   - 使用车次查询功能
   - 尝试购票和退票
   - 在我的订单中查看记录

3. **后续开发**:
   - 可以根据实际需求调整页面布局
   - 可以添加更多筛选和搜索功能
   - 可以集成图表库显示统计数据
